# Design Sprint Readiness Assessment — architecture-first public website

The challenge is to determine which full-site structure makes the `leptos-cf` reference implementation easiest to understand and adopt without weakening technical truth.

## Inputs Captured

**Challenge description:** Select and validate a multi-page visual and information system that turns the todo-first template surface into an architecture-first public reference website.

**Existing hypothesis:** A request-path field guide will clarify the stack and increase qualified start actions; the highest-risk assumption is that architecture-first explanation is more useful than demo-first interaction.

**Customer access status:** No recruiter, customer panel, or five-person Friday cohort is secured.

**Decider name and availability:** Repository owner is the likely Decider; required attendance windows are not confirmed.

**Team composition draft:** One owner/coordinator; no committed 4–7 person sprint roster.

**Prototype medium:** Generated full-page image directions plus an inspectable Visualize review can be produced in one day, but no Friday test is scheduled.

## Readiness Verdict: **Wait**

The challenge is sprint-worthy, but the canonical sprint cannot begin without a confirmed Decider, team, five consecutive days, and five target developers for Friday testing.

## Diagnosis

A full Design Sprint would be theater without customer testing and decision authority. The project can still use three independent structural explorations as a lightweight design-council input, because the operator delegated creative discretion; that is not equivalent to a completed five-day Design Sprint or validated customer direction.

## Recommended Preconditions

1. **Confirm Decider and attendance** (Repository owner; deadline: before any scheduled sprint Monday).
2. **Recruit five Rust-capable target developers** (Research owner; deadline: 7–10 days before Friday testing).
3. **Clear a 4–7 person core team for five days** (Decider; deadline: before scheduling).
4. **Approve the comprehension test and honorarium budget** (Decider; deadline: before recruiting).
