# Customer

## Segments & Best-Fit Customer

The best-fit early visitor is a Rust or full-stack engineer who wants Leptos SSR and hydration on Cloudflare Workers but does not want to rediscover Worker entrypoints, asset fallthrough, D1 scoping, build pinning, and release proof by trial and error. A secondary visitor is a coding agent that needs checked-in boundaries and deterministic commands. This is a proto-segment derived from repository intent, not user research.

| Segment | Job | Fit | Evidence |
|---|---|---|---|
| Rust/Leptos adopter | Evaluate and start an edge-deployed full-stack app. | Primary | `NORTH_STAR.md:3-10` |
| Coding agent | Follow explicit build, runtime, and release boundaries. | Secondary | `NORTH_STAR.md:5-12` |
| General SaaS buyer | Purchase or trial a hosted product. | Not targeted | No hosted offer exists. |
