# Marketing

## Target Market & Avatar

Niche: engineers evaluating a production-minded Leptos-on-Cloudflare starter. Primary goal: use the starter through the source-bound start path. USP: a public reference implementation that exposes every important runtime and release boundary instead of hiding it behind a black-box scaffold. This remains a hypothesis until external interviews or adoption data exist.

## Before / During / After Grid

| Phase | Square | Current state | Plan |
|---|---|---|---|
| Before | Awareness | Engineer wonders whether Leptos and Workers fit together cleanly. | Home makes the request path and two-runtime model legible. |
| Before | Trust | Engineer distrusts production-ready claims. | Evidence labels separate source, local verification, provider observation, and unknowns. |
| During | Adoption | Engineer needs exact first steps. | `/start` binds prerequisites, commands, and caveats to checked-in sources. |
| During | Evaluation | Engineer wants to inspect real behavior. | `/lab` exposes bounded D1-backed mutations. |
| After | Proof | Engineer needs release confidence. | Verification docs and exact-tree local proof remain distinct from deployment. |
